# 曼荼羅palette

色と言葉を選び、自由に配置した曼荼羅から、自分のストーリーを見つけるWebアプリです。

## 使い方

1. 何について考えるか、テーマを選ぶ（決めずに自由に始めることもできます）
2. 色とキーワードカードを選ぶ
3. 好きなフィールドを画像から選ぶ
4. カードを動かす。「距離で置く」では中心＝自分に近い／外側＝遠い の目安が表示されます（「自由に置く」も選べます）。大きさ＝大切さ、位置＝距離、色＝感覚として使えます
5. 完成した作品を眺め、気になる問いだけ選んで答える。作品にタイトルをつける
6. 作品・タイトル・答えを1枚のPNG画像で保存する（うまく開けないときは、表示された画像を長押しで保存、スマホでは「写真に保存・共有」も使えます）

キーワードの表示・非表示を切り替えられます。入力内容は外部AIやデータベースへ送信しません。再読み込みすると入力・配置は消えるため、書き終えたら画像保存してください。

## 開発

Node.js 24 / pnpm 11.25.0

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

## 公開設定
