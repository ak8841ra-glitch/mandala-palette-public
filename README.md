# 曼荼羅palette

色と言葉を選び、自由に配置した曼荼羅から、自分のストーリーを見つけるWebアプリです。

## 使い方

1. 何について考えるか、テーマを選ぶ（決めずに自由に始めることもできます）
2. 上の色パレットから色をタップして言葉を開き、気になる言葉をまとめて選ぶ（何色でも、何枚でも）
3. 好きなフィールドを画像から選ぶと、選んだカードがまとめて並ぶ
4. カードを動かす。「配置ガイド」を表示すると、フィールドごとの目安が出ます（三角＝①→②→③の順に置く3つの○、横一列＝過去→現在→未来、円＝内側↔外側）。カードを選ぶと大きさ・重なり（手前へ／奥へ）を変えられます
5. 完成した作品を眺め、気になる問いだけ選んで答える（三角フィールドでは、①本来の姿・②表面的な姿・③理想的な姿 という見方が表示されます）。作品にタイトルをつける
6. 作品・タイトル・答えを1枚のPNG画像で保存する（うまく開けないときは、表示された画像を長押しで保存、スマホでは「写真に保存・共有」も使えます）

キーワードの表示・非表示を切り替えられます。入力内容は外部AIやデータベースへ送信しません。途中の内容はこのブラウザの中だけに自動保存され、トップの「つづきから」で再開できます。

## 開発

Node.js 24 / pnpm 11.25.0

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

## 公開設定
