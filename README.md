# 曼荼羅palette

色と言葉を選んで今の気分を眺めたり、パーツと色を選んで曼荼羅アートをつくったりできるWebアプリです。トップページに2つの入口があります。

- **自分を眺める**：色と言葉を選び、フィールドに置いて眺める（下の「使い方」）
- **自分でつくる**：中心・内側・外側・全体を囲む輪のパーツを置き、色・数・大きさ・向きを整えて、曼荼羅アートを画像で保存する。「自分を眺める」の完成画面からは、選んだ色を持って移れます

## 使い方

1. 何について考えるか、テーマを選ぶ（決めずに自由に始めることもできます）
2. 色の輪をタップして言葉を開き、気になる言葉をまとめて選ぶ（何色でも、何枚でも。下へ進むと小さなパレットが上に出ます）
3. 「並べる」で、選んだカードが共通の曼荼羅フィールドにまとめて並ぶ
4. 配置ガイドを選んでカードを動かす（内側↔外側／①②③の順に置く3つの○／過去→現在→未来／ガイドなし）。カードを選ぶと大きさ・重なり・言葉を変えられます
5. 完成した作品を眺め、気になる問いだけ選んで答える（①②③ガイドでは、①本来の姿・②表面的な姿・③理想的な姿 という見方が表示されます）。作品にタイトルをつける
6. 作品・タイトル・答えを1枚のPNG画像で保存する（うまく開けないときは、表示された画像を長押しで保存、スマホでは「写真に保存・共有」も使えます）

キーワードの表示・非表示を切り替えられます。入力内容は外部AIやデータベースへ送信しません（AIは使っていません）。途中の内容はこのブラウザの中だけに自動保存され、トップの「つづきから」で再開できます。

## 開発

Node.js 24 / pnpm 11.25.0

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

## 公開設定
