# 設備のしくみ 3D（toilet-lab）

住宅設備の「部品の名前・場所・役割・つながり」を、3D模型を回しながら学ぶ個人学習用アプリです。今はトイレ（タンク式）とエアコン（壁かけ形）の2ステージがあります。
代表的な構造を簡略化した模型で、特定メーカーの製品や修理手順を示すものではありません。

## 起動方法

Node.js 22.12 以上 / pnpm 11

```sh
cd toilet-lab
pnpm install
pnpm dev        # http://127.0.0.1:5174/ を開く
```

- `pnpm build` … 型チェックと本番用ビルド（`dist/`）
- `pnpm preview` … ビルド結果を http://127.0.0.1:4174/ で確認
- `?nowebgl` を付けて開くと、WebGL が使えないとき用の「部品一覧」表示を確認できます

## できること

- ドラッグ／タッチで回転、ホイール／ピンチで拡大縮小、「全体に戻る」
- 「内部を見る」：タンクのふたを持ち上げ、便器・タンク・便ふたを半透明に、壁と床の一部を切り取って配管を表示
- 部品をタップ（または名前ラベルをタップ）→ 強調表示と説明（正式名称・よくある呼び方・役割・つながり・詳しく・用語）
- 検索：名前・よみ・言い換え（例「水を止める」「浮き球」「におい」）で候補表示 → 選ぶとその部品へズーム（必要なら内部表示に切り替え）
- ズームに応じてラベルの数が変わる（全体＝主要設備のみ → 近づくと細部）。ラベル同士・画面上のボタンとの重なりを避けて配置
- 「水を流す」：レバー → フロートバルブ → 便器 → トラップ → 排水管、浮き球 → ボールタップ → 給水、補助水管 → 封水回復 を6段階の矢印アニメーションで表示
- 「あそぶ」（または左上の名前）→ ステージ選択：1 トイレ・2 エアコンが遊べる（3 水栓・4 ブレーカーは準備中）。各ステージで「迷子パーツ」「部品クイズ」「模型を見る」を選べる
- エアコンの「冷房する」：圧縮機 → 室外熱交換器 → 膨張弁 → 液管 → 室内熱交換器 → ガス管 → 圧縮機の冷媒の循環と、冷えた風・外へ捨てる熱・ドレン水を6段階で表示
  - 迷子パーツをもどそう：5つの候補から1つの部品が模型の外へ迷子に。ドラッグで運ぶか、元の場所をタップして戻す。まちがえると本人がヒントを出し、戻ると水を流して働く様子を見せてクリア
  - 部品クイズ（3問）：間違えるとヒント、正解すると役割を一文で表示

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/stages/index.ts` | ステージの並び（準備中のものも含む） |
| `src/stages/types.ts` | ステージが用意するデータの形 |
| `src/stages/<ステージ>/parts.ts` | 部品の説明データ（名称・言い換え・役割・つながり・補足） |
| `src/stages/<ステージ>/model.ts` | 基本形状で作る3D模型と、その動き（外部素材なし） |
| `src/stages/<ステージ>/flow.ts` | 「水を流す」「冷房する」の台本（時間ごとの説明と矢印） |
| `src/stages/<ステージ>/info.ts` | 参考資料URL・模型の範囲・省略点・クイズ・迷子パーツのセリフ |
| `src/stages/<ステージ>/index.ts` | カメラ位置などの設定をまとめたステージ定義 |
| `src/three/Viewer.ts` | カメラ・選択・内部表示・ラベル配置・アニメーション・迷子パーツ（全ステージ共通） |
| `src/three/kit.ts` | 模型づくりの共通道具（基本形状と部品登録） |
| `src/search.ts` | 検索（ひらがな・カタカナを同一視） |

React + TypeScript + Three.js（Vite）。実行時のAI API・バックエンド・アクセス解析は使っていません。
